# Go Generate 簡介

`go generate` 是 Go 語言內建的一個工具，用於自動化執行代碼生成指令。它與 `go build` 或 `go test` 不同，它不會自動執行，必須手動觸發。

## 1. 基本原理

`go generate` 會掃描專案中的 `.go` 檔案，尋找符合特定格式的註解（Directive）：

```go
//go:generate <command> <arguments>
```

當你執行 `go generate ./...` 時，Go 會解析這些註解並在當前目錄下執行對應的命令。

---

## 2. 為什麼要使用代碼生成？

- **減少重複勞動**：自動生成樣板代碼 (Boilerplate)。
- **類型安全**：將原本需要使用 `interface{}` 或反射的邏輯，在編譯前生成強類型的代碼。
- **效能提升**：預先計算或生成靜態查找表，避免執行期的運算開銷。
- **同步元資料**：例如根據資料庫 Schema 或 Protobuf 定義自動生成 Go 結構體。

---

## 3. 常用指令

- `go generate`：掃描當前目錄。
- `go generate ./...`：遞迴掃描整個專案。
- `go generate -v`：顯示執行的詳細過程。
- `go generate -x`：顯示執行了哪些具體的作業系統指令。

---

## 4. 常見的生成工具

- **stringer**：為列舉類型 (Enum) 自動生成 `String()` 方法。
- **mockgen**：為介面生成 Mock 實作（測試用）。
- **wire**：自動化依賴注入。
- **gorm-gen**：為 GORM 生成類型安全的查詢代碼。
- **jsoniter**：生成高效能的 JSON 序列化代碼。

---

## 5. 注意事項

1. **不要手動修改生成的檔案**：通常生成的檔案頂部會有一行 `// Code generated by ... DO NOT EDIT.`。
2. **將生成指令寫在合適的地方**：通常建議寫在與該生成邏輯最相關的檔案頂部。
3. **版本控制**：生成的檔案是否應該提交到 Git 視團隊規範而定（通常建議提交，以確保 CI/CD 環境不需要重新生成）。
