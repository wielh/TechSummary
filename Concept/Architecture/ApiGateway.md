# API Gateway 作用

+ **路由和轉發請求**：API 閘道根據請求的路徑、方法、標頭等訊息，將請求路由到相應的後端服務。

+ **協定轉換**： API 閘道可以將來自客戶端的請求從一種協定轉換為另一種協定。例如：將 HTTP 請求轉換為 Protocol Buffers 格式的請求。

+ **請求和回應轉換**：API 閘道可以在請求和回應之間進行資料格式轉換。例如：將 XML 格式轉換為 JSON 格式。

+ **認證與授權**：API 閘道可以在請求到達後，進行使用者認證和授權驗證。

+ **負載平衡**：API 閘道可以將請求分發到多個服務實例中，以實現負載平衡和高可用性。

+ **監控和日誌記錄**：API 閘道可以收集請求和回應的指標數據，並記錄詳細的日誌資訊。
